# Datasets

Each dataset is **downloaded manually** from its official source and placed under `data/`.
Datasets are **never committed** to git (`data/` is git-ignored except this file).
They are never merged into one training set; every row carries a `source` column.

Datasets used (place them as `data/cic_pqc_oav/` and `data/cic_ids2017/`):

1. **CIC-PQC_OAV**
2. **CIC-IDS2017**

Planned but **not used**: BCCC-UDP-QUIC-IDS-2025 (QUIC is outside what the lab captured).

Cite each dataset as its official distribution page requires; see the top-level `README.md`.
